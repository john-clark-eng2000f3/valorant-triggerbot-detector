# valorant-triggerbot-detector

I got tired of manually scrubbing through replay files to spot triggerbot users. This thing walks the kill feed and camera angles in local replays, looks for the telltale frame-perfect flick-and-fire patterns, and spits out timestamps worth a second look.

## usage

Replay parsing is CPU-bound; don't expect it to be fast on a full night's matches.
